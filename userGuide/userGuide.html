Impala Demo Edition

Player Guide

This is an interface demo. It runs without account sign-in, an Impala API, or a metadata backend. The local metadata.json file supplies sample catalog information and artwork.

Listen

Choose a track in the track list or use the previous, play, pause, and next controls. Playback controls, shuffle, repeat, filters, and saved interface preferences run in your browser.

Explore the library

Open Library to browse and edit the demo playlist. The KW Player Dropbox playlist is included as the default example.

Media URLs

Audio and video files are loaded directly from the URLs in songs-ks.js and metadata.json. Replace those sample URLs with media intended for public playback. The demo app itself does not proxy or store media.

Settings

Settings customize the palette, player text, and local metadata display. Cloud and account services are not configured in this edition.
