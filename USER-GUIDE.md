# Impala Demo user guide

This demo runs without sign-in, an Impala API, or a metadata backend. See [`userGuide/userGuide.html`](userGuide/userGuide.html) for the player walkthrough.

The catalog comes from local `metadata.json` and contains three albums, three tracks, two videos, and five approved public webcast URLs. Playback connects directly to the media hosts; it does not use an Impala backend or proxy.
